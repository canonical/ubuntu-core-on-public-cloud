# Issue tracker for Ubuntu Core on the public clouds

This repository is intended to track issues related to Ubuntu Core images on the public cloud. If you have been trying Ubuntu Core on any of the public clouds, and have faced any issue while doing so, this is the place to report it.

## What is Ubuntu Core?

[Ubuntu Core](https://ubuntu.com/core) is the immutable flavor of Ubuntu. It pairs the robustness and ecosystem Ubuntu is known for with a modular architecture that lets you compose tailored systems from strictly-confined building blocks, known as snaps.

## Why use Ubuntu Core on a Public Cloud?

Ubuntu Core has been refined over ten years of production deployment on constrained IoT-type devices. With the new cloud-optimized version of Ubuntu Core, enterprise users can get the same drift-free and resilient operational model for cloud appliances and managed services.

It is currently in public preview, and we are actively seeking feedback from users who are testing it out.

## Documentation

For details about usage and current status, refer to our [documentation about Ubuntu Core on the public clouds](https://documentation.ubuntu.com/core-on-clouds/).

## Creating issues

You can report any problems that you face with the Ubuntu Core images here in the issue tracker repo. It could be about something not working, some missing cloud-agent functionality or anything else including general feedback. When reporting a problem, please include the cloud platform, region, instance type and relevant serial-console or system logs where possible.

You can find existing issues here: [https://github.com/canonical/ubuntu-core-on-public-cloud/issues](https://github.com/canonical/ubuntu-core-on-public-cloud/issues.).

For more general issues related to Ubuntu Core or snaps (other than the public cloud guest agents), please refer to the [Ubuntu Core](https://documentation.ubuntu.com/core/) and [Snapcraft](https://snapcraft.io/docs/) documentation or report them in the [snapcraft forum](https://forum.snapcraft.io/).
